# radiomics-ml-portfolio

# ML-анализ радиомических данных: диагностика подагры

Этот проект представляет собой пайплайн машинного обучения для бинарной классификации (норма/патология) на основе извлеченных радиомических признаков (КТ суставов). 

## 🎯 Задача
Построить надежную классификационную модель, которая по числовым характеристикам (текстура, форма, интенсивность) может отличить здорового пациента от пациента с подагрой, минимизируя риск переобучения.

## 🛠 Стек технологий
*   Python 3.9
*   Pandas / NumPy — обработка и манипуляция табличными данными.
*   Scikit-learn — построение пайплайна, кросс-валидация, обучение логистической регрессии.
*   SciPy / Statsmodels — статистические тесты (Манна-Уитни), FDR-коррекция (Benjamini-Hochberg), фильтрация высококоррелированных признаков.

## 🧠 Архитектура решения
В скрипте `gout_analyse.py` реализован продвинутый подход к отбору признаков и валидации, который предотвращает утечку данных:

1.  Разделение данных (Train/Test): Данные разделяются до любого отбора признаков (80/20, со стратификацией).
2.  Предварительный скрининг (на Train): Непараметрический тест Манна-Уитни с поправкой на множественные сравнения (FDR).
3.  Иерархическая кластеризация: Удаление высококоррелированных признаков (мультиколлинеарности) с помощью построения дендрограммы. Из каждого кластера оставляется самый статистически значимый признак.
4.  Отбор по размеру эффекта: Выбор топ признаков, оказывающих наибольшее влияние (оценка через Z-score и r).
5.  Вложенная кросс-валидация: Оценка качества модели происходит с 5 фолдами, где отбор наиболее информативных признаков происходит внутри каждого фолда. Это дает честную оценку обобщающей способности модели.

## 📊 Результаты
Модель: Логистическая регрессия с L2-регуляризацией и масштабированием.

Формула логистической регрессии:
z = -0,043+3,974x_1+ 2,990x_2

x1 - original_firstorder_RootMeanSquared (среднеквадратичное значение (RMS))
x2 - wavelet-LLL_firstorder_Median (медиана (wavelet-LLL))
